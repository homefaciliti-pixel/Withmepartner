1. LOGIN API
================================================================================

1.1 Login with Mobile Number & Password
Endpoint: POST /auth/login
Auth required: No
Content-Type: application/json

Request Body:
{
  "country_code": "+91",  // Optional, defaults to "+91"
  "mobile_number": "9876543210",
  "password": "MySecurePass123"
}

Success Response — 200 OK:
{
  "status": true,
  "message": "Login successful",
  "data": {
    "user_id": "usr_10234",
    "name": "Rahul Sharma",
    "country_code": "+91",
    "mobile_number": "9876543210",
    "profile_completed": true,
    "profile_step_pending": null,
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "rft_7f9e2a...",
    "token_expires_in": 3600
  }
}

Error Responses:
{ "status": false, "message": "Invalid mobile number or password", "error_code": "INVALID_CREDENTIALS" }
{ "status": false, "message": "Account not found. Please register.", "error_code": "USER_NOT_FOUND" }
{ "status": false, "message": "Account temporarily locked due to multiple failed attempts", "error_code": "ACCOUNT_LOCKED" }

2. FORGOT PASSWORD API
================================================================================
Flow: Send OTP -> Verify OTP -> Reset Password

2.1 Send OTP
Endpoint: POST /auth/forgot-password/send-otp
Auth required: No
Content-Type: application/json

Request Body:
{
  "country_code": "+91",
  "mobile_number": "9876543210"
}

Success Response — 200 OK:
{
  "status": true,
  "message": "OTP sent successfully",
  "data": {
    "otp_session_id": "otp_sess_a1b2c3",
    "otp_expires_in": 300,
    "country_code": "+91",
    "mobile_number": "9876543210"
  }
}

Error Response:
{ "status": false, "message": "Mobile number not registered", "error_code": "USER_NOT_FOUND" }


2.2 Verify OTP
Endpoint: POST /auth/forgot-password/verify-otp
Auth required: No
Content-Type: application/json

Request Body:
{
  "otp_session_id": "otp_sess_a1b2c3",
  "otp": "4829"
}

Success Response — 200 OK:
{
  "status": true,
  "message": "OTP verified",
  "data": {
    "reset_token": "rst_tok_9f8e7d",
    "reset_token_expires_in": 600
  }
}

Error Responses:
{ "status": false, "message": "Invalid OTP", "error_code": "INVALID_OTP" }
{ "status": false, "message": "OTP expired, please resend", "error_code": "OTP_EXPIRED" }


2.3 Reset Password
Endpoint: POST /auth/forgot-password/reset
Auth required: No (uses reset_token)
Content-Type: application/json

Request Body:
{
  "reset_token": "rst_tok_9f8e7d",
  "new_password": "NewSecurePass456",
  "confirm_password": "NewSecurePass456"
}

Success Response — 200 OK:
{
  "status": true,
  "message": "Password reset successful. Please login with your new password.",
  "data": null
}

Error Responses:
{ "status": false, "message": "Passwords do not match", "error_code": "PASSWORD_MISMATCH" }
{ "status": false, "message": "Reset session expired, please try again", "error_code": "RESET_TOKEN_EXPIRED" }

3. REGISTER API
================================================================================
Flow: Verify Phone via OTP first -> fill rest of form -> submit registration

3.1 Send OTP (Registration)
Endpoint: POST /auth/register/send-otp
Auth required: No
Content-Type: application/json

Request Body:
{
  "country_code": "+91",
  "mobile_number": "9876543210"
}

Success Response — 200 OK:
{
  "status": true,
  "message": "OTP sent successfully",
  "data": {
    "otp_session_id": "otp_sess_x9y8z7",
    "otp_expires_in": 300,
    "country_code": "+91",
    "mobile_number": "9876543210"
  }
}

Error Response:
{ "status": false, "message": "Mobile number already registered", "error_code": "MOBILE_ALREADY_EXISTS" }


3.2 Verify OTP (Registration)
Endpoint: POST /auth/register/verify-otp
Auth required: No
Content-Type: application/json

Request Body:
{
  "otp_session_id": "otp_sess_x9y8z7",
  "otp": "5739"
}

Success Response — 200 OK:
{
  "status": true,
  "message": "Mobile number verified",
  "data": {
    "token": "vtok_5c4b3a",
    "verification_token_expires_in": 1800
  }
}

Error Response:
{ "status": false, "message": "Invalid OTP", "error_code": "INVALID_OTP" }


3.3 Complete Registration
Endpoint: POST /auth/register
Auth required: No (uses verification token)
Content-Type: application/json

Request Body:
{
  "token": "vtok_5c4b3a",
  "name": "Rahul Sharma",
  "country_code": "+91",
  "mobile_number": "9876543210",

  "city": "Jaipur",
  "state": "Rajasthan",
  "pincode": "302021",
  "password": "MySecurePass123",
  "confirm_password": "MySecurePass123"
}

Success Response — 201 Created:
{
  "status": true,
  "message": "Registration successful",
  "data": {
    "user_id": "usr_10234",
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "rft_7f9e2a...",
    "token_expires_in": 3600,
    "profile_step_pending": "PROFILE_PHOTO"

Error Responses:
{ "status": false, "message": "Passwords do not match", "error_code": "PASSWORD_MISMATCH" }
{ "status": false, "message": "Verification session expired. Please verify mobile number again.", "error_code": "VERIFICATION_TOKEN_EXPIRED" }
{ "status": false, "message": "Email already registered", "error_code": "EMAIL_ALREADY_EXISTS" }
{ "status": false, "message": "Invalid pincode", "error_code": "INVALID_PINCODE" }

10. PROFILE PHOTO API
================================================================================

10.1 Upload Profile Photos
Endpoint: POST /profile/photos
Auth required: Yes (Headers: Authorization: Bearer <access_token>)
Content-Type: multipart/form-data

Form Fields:
- primary_photo (file, required): Main scanned/captured photo (JPG/PNG)
- additional_photos (file[], max 4, required): Up to 4 more photos (JPG/PNG)

Success Response — 201 Created:
{
  "status": true,
  "message": "Profile photos uploaded successfully",
  "data": {
    "photos": [
      { "photo_id": "ph_001", "url": "https://cdn.yourdomain.com/usr_10234/ph_001.jpg", "is_primary": true },
