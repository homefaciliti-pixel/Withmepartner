================================================================================
                    WITH ME 24 PARTNER - FULL API DOCUMENTATION
================================================================================

BASE URL: http://localhost:5000 (or your Render domain e.g. https://your-app.onrender.com)
PERSISTENT STORE: MySQL Database (homefaciliti.com / node_partner_users table) & store/users.json disk backup
DLT SMS GATEWAY: SMSGATEWAYHUB (EntityID: 1201173444411453897, TemplateID: 1207173589889308632, Sender: HMFCLI)
FEATURES:
 - Real DLT SMS OTPs: Dispatches SMS via SMSGATEWAYHUB API for registration & forgot-password.
 - MySQL Database Sync: Automatically initializes table `node_partner_users` on homefaciliti.com and syncs user profiles in real-time.
 - Dynamic Image URLs: Image URLs automatically detect your Render domain (via process.env.RENDER_EXTERNAL_URL / process.env.BASE_URL or request Host header).
 - Flexible Phone Matching: (+91 / 91 / 0 prefix normalization).
 - Default Uploaded Photos: (photo_1.jpg .. photo_5.jpg) auto-assigned on registration.

1. LOGIN API
================================================================================

1.1 Login with Mobile Number & Password
Endpoint: POST /auth/login
Auth required: No
Content-Type: application/json

Request Body:
{
  "country_code": "+91",  // Optional, defaults to "+91"
  "mobile_number": "9876543210",
  "password": "MySecurePass123"
}

2. FORGOT PASSWORD API
================================================================================
Flow: Send OTP -> Verify OTP -> Reset Password

2.1 Send OTP
Endpoint: POST /auth/forgot-password/send-otp
Auth required: No
Content-Type: application/json

Request Body:
{
  "country_code": "+91",
  "mobile_number": "9876543210"
}

Success Response — 200 OK:
{
  "status": true,
  "message": "OTP sent successfully",
  "data": {
    "otp_session_id": "otp_sess_a1b2c3",
    "otp_expires_in": 300,
    "country_code": "+91",
    "mobile_number": "9876543210"
  }
}


2.2 Verify OTP
Endpoint: POST /auth/forgot-password/verify-otp
Auth required: No
Content-Type: application/json

Request Body:
{
  "otp_session_id": "otp_sess_a1b2c3",
  "otp": "4829"
}

Success Response — 200 OK:
{
  "status": true,
  "message": "OTP verified",
  "data": {
    "reset_token": "rst_tok_9f8e7d",
    "reset_token_expires_in": 600
  }
}


2.3 Reset Password
Endpoint: POST /auth/forgot-password/reset
Auth required: No (uses reset_token)
Content-Type: application/json

Request Body:
{
  "reset_token": "rst_tok_9f8e7d",
  "new_password": "NewSecurePass456",
  "confirm_password": "NewSecurePass456"
}

Success Response — 200 OK:
{
  "status": true,
  "message": "Password reset successful. Please login with your new password.",
  "data": null
}
